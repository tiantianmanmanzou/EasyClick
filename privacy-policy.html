EasyClick Privacy Policy

Effective date: July 9, 2026

This privacy policy applies to the EasyClick browser extension.

1. What EasyClick Does

EasyClick is a browser extension for front-end inspection and page-element analysis. It helps users inspect elements on the current page, copy selectors, review layout information, and perform visual debugging actions only after the user actively launches the extension.

2. What Information EasyClick Can Access

When the user activates EasyClick on a page, the extension may access information from the current page that is necessary to provide its features, including:

  • The current page URL and page title
  • Page structure and DOM content needed for element inspection
  • Text, attributes, selectors, XPath values, and related metadata of user-selected elements
  • Local extension settings such as toolbar visibility and copy-selector preferences
  • Console error information from the current page if the user has enabled related copy features

3. How EasyClick Uses Information

EasyClick uses the information above only to provide its visible extension features on the page the user is actively working with. This includes showing overlays, copying selectors or page context to the clipboard, toggling UI preferences, and supporting front-end debugging workflows.

EasyClick works in response to explicit user actions. It is not intended to silently collect browsing data for analytics, advertising, or profiling.

4. Data Storage

EasyClick stores limited configuration data locally in the browser so that user preferences can persist across sessions. Examples include whether the toolbar is shown or hidden and which Copy Selector fields are enabled.

This locally stored information is used only for the extension’s functionality.

5. Data Transmission and Sharing

EasyClick does not sell user data.

EasyClick does not transfer collected page content or user-selected element data to the developer’s servers.

EasyClick does not share such data with third parties, except where browser features chosen by the user require local browser handling, such as copying content to the clipboard.

6. Permissions

EasyClick may request browser permissions such as activeTab, contextMenus, scripting, storage, tabs, and host access in order to operate on the page the user has chosen to inspect.

These permissions are used only to support extension features and not for advertising, tracking, or unrelated data collection.

7. Third-Party Services

EasyClick does not rely on third-party analytics or advertising SDKs to process user browsing data.

8. Changes to This Policy

This privacy policy may be updated from time to time. Any updated version will be published at this page with a revised effective date.

9. Contact

If you have questions about this privacy policy or EasyClick, please contact the developer through the project repository:
